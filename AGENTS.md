# heist-go

Public Go SDK (`heist/`) and CLI (`cmd/heist/`) for the Heist external REST API.
This repository is public: never commit credentials, customer data, or details of
private Heist services beyond the published OpenAPI contract.

## Boundaries

- The SDK owns the REST client, request/response types, authentication, error
  handling, and pagination. Keep CLI commands, output formatting, and progress
  handling in `cmd/heist/`. Terraform state and lifecycle behavior belong in the
  separate `terraform-provider-heist` repository.
- Code must not depend on private Heist packages or repositories.
- The service owns the contract. Preserve the API's field names and semantics.

## CLI commands

A terminal UI is planned, so keep commands easy to reuse from another front end:

- Keep API calls separate from output. Rendering functions take typed data and
  an `io.Writer`, for example `writeFindingDetail` in `cmd/heist/findings.go`.
- Commands must run from flags and arguments alone. Never prompt; scripts and
  CI rely on their output and exit codes.
- Keep logic in `cmd/heist/` until a second front end needs it, then move it to
  the SDK rather than duplicating it.

## Generated code

`heist/openapi.gen.go` is generated by oapi-codegen from `api/openapi.json`. Do
not edit it by hand. Change `heist/oapi-codegen.yaml` or update the snapshot and
run `make generate`. Generated responses must keep decoding fields and enum
values added by later API releases; don't add strict response validation.

Never edit `api/openapi.json`; use `go run ./internal/cmd/update-openapi <version>`
to replace it with a published version. See the README for details.

## Checks

Run `make check` before handing off. It verifies formatting, vet, tests, the CLI
build, and that generated code matches the snapshot.
